# Module ru-bizgen

Генератор российских (и не только) тестовых данных: IntelliJ IDEA Plugin и MCP-сервер.
Все данные генерируются локально, без обращений к внешним сервисам.

## Guides

Интерактивные презентации по проекту открываются из вкладки **Guides** в шапке
этой документации (рядом с навигацией Dokka).

В Guides — разборы архитектуры, сборки и других тем в формате слайдов:
оглавление, клавиатура, без отдельной «хаб-страницы». Список пополняется вместе
с репозиторием; актуальный набор всегда в меню **Guides**.
