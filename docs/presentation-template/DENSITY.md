# Антипустые слайды — шпаргалка плотности

Короткий экран для ревью `outline.md` и HTML. Полные бюджеты:
[`OUTLINE_CRITERIA.md`](OUTLINE_CRITERIA.md). HTML-контракт: [`TEMPLATE.md`](TEMPLATE.md).

## Цель

Контентный слайд заполняет **~80–100%** полезной площади карточки.
`hero` может быть просторным. Режим: **reading-first**.

## Симптомы → действие

| Симптом                                         | Действие                                                        |
|-------------------------------------------------|-----------------------------------------------------------------|
| Нижняя половина карточки пустая (~30% контента) | Добить блоки того же тезиса **или** смержить со смежным слайдом |
| 3 коротких буллета на весь `content`            | Расширить до 4–6 / добавить callout / merge                     |
| `cards-2x2` с одним предложением без списка     | Абзац + `method-card__list` (2–5 пунктов)                       |
| `comparison` из 3 коротких строк в колонке      | 4–5 пунктов + низ «когда выбирать» / callout                    |
| `facts` с note из 5 слов                        | 1–2 предложения в `fact__note`                                  |
| Pipeline из одних ярлыков (Init/Configure…)     | Подписи «ярлык · смысл» + diagram/легенда                       |
| Два соседних чеклиста                           | Один `comparison` / duo                                         |
| Pros / cons / comparison тремя слайдами         | Один comparison + нижний блок выбора                            |
| SVG: стрелка в пустоту, текст вылез из узла     | Компактные узлы; длинные подписи в 2 строки; рёбра к граням     |
| «На всякий случай короткий слайд»               | Не плодить воздух: плотность важнее короткого счётчика          |

## Писать куда

- Бюджеты типов → ближе к **верхней** границе.
- Merge фиксировать в outline: `# Замечания по плотности`.
- Контентные слайды в HTML → `deck--fill` (см. TEMPLATE).
