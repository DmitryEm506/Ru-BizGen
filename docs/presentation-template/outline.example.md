# Общий замысел

Одним абзацем: зачем создаётся презентация и что аудитория должна понять или
сделать после просмотра.

# Замечания по плотности

| Было | Стало | Почему |
|---|---|---|
| (пример) два коротких чеклиста | один comparison duo | иначе полупустые слайды |

Под особым контролем при HTML: …

## Слайд 1 — Название

Тип: hero

Главный тезис: одна сильная фраза.

Содержание:
- контекст, версия или дата;
- короткое название;
- пояснение ценности в 1–2 предложениях.

## Слайд 2 — Проблема

Тип: cards-2x2

Главный тезис: почему тема требует внимания.

Содержание:
1. Kicker: Контекст; Title: Короткий заголовок;
   Text: Одно-два предложения, что не так и почему это важно для читателя.
   Буллеты: симптом A; цена бездействия; кого затрагивает.
2. Kicker: Риск; Title: …;
   Text: …;
   Буллеты: …; …; …
3. Kicker: …; Title: …; Text: …; Буллеты: …; …
4. Kicker: …; Title: …; Text: …; Буллеты: …; …

Визуал: deck--fill + method-grid 2×2 (абзац + список в каждой карточке).

Обязательные факты:
- факт или метрика, которые нельзя потерять при редактуре.

## Слайд 3 — Как это работает

Тип: pipeline

Главный тезис: краткое объяснение процесса.

Содержание:
1. Init · что происходит на шаге
2. Configure · …
3. Execute · …
4. Result · …

Визуал: pipeline + при необходимости SVG/легенда; не оставлять низ пустым.

## Слайд 4 — Технический пример

Тип: code

Главный тезис: что доказывает пример.

```kotlin
// Вставьте реальный код, который нужно сохранить дословно.
fun example(): String = "value"
```

Пояснения:
- что важно заметить;
- какое ограничение действует;
- какой вывод следует из примера;
- (опционально) что ещё есть рядом в проекте.

## Слайд 5 — Сравнение

Тип: comparison

Главный тезис: чем отличаются два подхода.

Левая колонка:
- название подхода A;
- пункт;
- пункт;
- пункт;
- пункт;

Правая колонка:
- название подхода B;
- пункт;
- пункт;
- пункт;
- пункт;

Нижний блок «Когда выбирать»:
- бери A, если …;
- бери B, если …;
- общее ограничение / общий вывод.

Визуал: deck--fill + duo-grid + callout снизу.

## Слайд 6 — Рекомендации

Тип: checklist

Главный тезис: что делать дальше.

Содержание:
1. Первый шаг.
2. Второй шаг.
3. Третий шаг.
4. Четвёртый шаг.
5. Пятый шаг.

Финальный вывод: одна запоминающаяся фраза.
