## [1.12] - 24-08-2026

### 🚀 Новое

- Реализован MCP-сервер (`ru-bizgen-mcp`) — генераторы Ru BizGen теперь доступны вне IntelliJ IDEA через
  [Model Context Protocol](https://modelcontextprotocol.io) (Streamable HTTP, Ktor/Netty). Поддерживается подключение
  к MCP-клиентам (Cursor, Claude Desktop, Cline и др.). 5 категорийных инструментов `ru-bizgen_generator_<category>`
  с параметрами `type` (enum — генератор внутри категории) и `count` (до 1000 значений за вызов). Сервер запускается
  локально, данные генерируются без обращений к внешним сервисам
- Добавлен `Dockerfile` и `docker-compose.yml` для контейнерного запуска MCP-сервера
- Добавлен healthcheck-эндпоинт `GET /health` (`{"status":"UP"}`) для мониторинга MCP-сервера
- Добавлен генератор паспорта РФ (с пробелом) — серия с реальными кодами регионов ОКАТО + номер
- Добавлен генератор паспорта РФ (без пробела) — компактный формат
- Добавлен генератор загранпаспорта РФ (номер) — 9 цифр, серия 70/71
- Добавлен генератор загранпаспорта РФ (MRZ) — машинно-читаемая зона по стандарту ICAO 9303 (TD-3)
- Добавлен настраиваемый символ обрамления для вставки в редактор (двойная кавычка, одинарная кавычка, без обрамления)
- Добавлена возможность переименования генераторов в настройках плагина
- В Dokka Guides добавлены интерактивные презентации: ArchUnit и Gradle

### 🛠 Исправлено

- **Расчётный счёт (RUB/CNY)** — контрольный разряд теперь рассчитывается по Положению ЦБ РФ № 515 через
  `AccountKeyAlgorithm` (ранее был захардкожен как `0`)
- **Корреспондентский счёт** — переход на единый алгоритм `AccountKeyAlgorithm` (ранее использовался упрощённый
  алгоритм с весовыми коэффициентами, не учитывающий РКЦ)
- **IBAN РФ** — исправлена структура BBAN: 29 цифр формируются как `5 (суффикс БИК) + 4 (филиал) + 20 (счёт)`.
  Ранее структура содержала некорректные контрольные цифры и признак счёта, что могло приводить к невалидным IBAN
- **ОГРН ЮЛ** — исправлена контрольная сумма: `mod 11` вместо `mod 13` (контрольные алгоритмы ЮЛ и ИП были перепутаны)
- **ОГРН ИП** — исправлена контрольная сумма: `mod 13` вместо `mod 11`
- **ОГРН (ЮЛ и ИП)** — код региона теперь выбирается случайно (ранее был захардкожен как `61` — Самарская область)
- **СНИЛС** — исправлен диапазон генерируемых цифр: `0..9` вместо `1..9` (первая цифра могла быть только `1`)
- **ИНН** — код региона теперь может принимать значение `99` (верхняя граница диапазона была исключающей)
- **MCP** — категорийные тулы объявляют `outputSchema`, а `structuredContent` возвращается для любого
  успешного вызова, включая `count = 1` (раньше при одном значении структурированный результат
  отсутствовал, что расходилось со спецификацией MCP). В `structuredContent` поле `partial`
  присутствует всегда
- **MCP** — русскоязычные логи сервера больше не искажаются в консоли Windows: в `installDist`
  проставляется `-Dfile.encoding=UTF-8`

### ⚙️ Технические изменения

- Обновлены зависимости:
    - Kotlin `2.3.0` → `2.4.0`
    - IntelliJ Platform Gradle Plugin `2.16.0` → `2.18.1`
    - Kotest `6.1.2` → `6.2.1`
    - Kover `0.9.8` → `0.9.9`
    - ArchUnit `1.5.0`
    - Kodein DI `7.33.0`, kotlinx-coroutines `1.11.0` (integration-тесты)
- Добавлены MCP Kotlin SDK `0.15.0` и Ktor `3.5.1` (для модуля `ru-bizgen-mcp`)
- Реализован composite build `build-logic` с convention plugins (kotlin, testing, dokka, dokka-root, kover)
- Добавлен модуль `ru-bizgen-archunit`: исполняемые границы модулей, слои core, naming Generator↔Benchmark
  (вместо прежней валидации бенчмарков в perf)
- Добавлены UI integration-тесты на базе JetBrains IDE Starter + Driver SDK (source set `integrationTest/`);
  покрыты popup генераторов, настройки, уведомления, буфер, символ обрамления, переименование и сброс
- Задача `integrationTest` отвязана от `check` — UI-тесты не входят в обычный CI и запускаются ночью
  через `ci-integration.yml`
- Расширены тесты генераторов: добавлены проверки контрольных сумм для счёта, IBAN, ИНН и ОГРН
- Из отчёта покрытия Kover исключены классы source set `integrationTest` — они компилируются вместе
  с плагином и учитывались как непокрытый продакшен-код; исправлено и имя исключаемого UI-пакета
- Убрана недекларированная зависимость на Gson из IntelliJ Platform: глубокое копирование настроек
  переведено на `XmlSerializer` платформы — тот же механизм, которым настройки уже персистятся
- Kotlin stdlib больше не упаковывается в плагин: его предоставляет IntelliJ Platform. Размер
  артефакта уменьшился с 2,03 МБ до 0,30 МБ, снят риск конфликта загрузчиков на будущих версиях IDE
- `ci-all.yml` выполняет два прогона `check` — обычный и с `-PrunDistanceFinderTests`: флаг включает
  `includeTags` и сам по себе запускает только тесты уникальности
- Ключ кэша IDE в `ci-integration.yml` вычисляется из версии проекта, а не задан константой
- В `ci-main.yml` добавлен обязательный шаг `verifyPlugin`: артефакт проверяется IntelliJ Plugin
  Verifier на краях заявленного диапазона совместимости — минимальной поддерживаемой версии
  (`sinceBuild = 242`), целевой сборке и последнем вышедшем релизе платформы. Раньше верификация
  не запускалась ни в одном workflow. Полная матрица версий вынесена под флаг `-PverifyAllIdes`
  и вход `verifyAllIdes` в `ci-all.yml`
- Подтверждена совместимость с **IntelliJ IDEA 2026.2**: плагин проверен верификатором на
  `IU-262.8665.258` без пересборки под новую платформу
