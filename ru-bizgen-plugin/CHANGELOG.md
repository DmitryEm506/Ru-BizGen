## [1.11] - 31-03-2026

### 🚀 Новое

- Добавлены генераторы формирования номера российского мобильного телефона:
    - в формате: `+7 (XXX) NNN-NN-NN`
    - только цифры: `7XXXNNNNNNN`  
      где `XXX` — коды популярных российских операторов связи (МТС, Билайн, Мегафон, Tele2)
- Обновлена подсказка для параметра дистанции в настройках плагина: добавлено пояснение, что при значении `130` дальнейшая проверка не
  выполняется, и фактическая дистанция может быть значительно больше
- Реализован адаптивный алгоритм обновления сохранённых пользовательских настроек. Важно: настройки генераторов больше не сбрасываются при
  обновлении плагина — порядок и выбранные действия сохраняются автоматически. При изменении списка генераторов:
    - сохраняются пользовательские настройки генераторов (порядок и признак включения);
    - новые генераторы добавляются в конец списка и по умолчанию включаются;
    - устаревшие генераторы автоматически удаляются из списка (порядок оставшихся корректируется).

### 🛠 Исправлено

- В режиме уведомления «Всплывающая подсказка» добавлено ограничение на длину выводимого сообщения — не более 100 символов
- Исправлена опечатка в названии генератора: «Расчётный RUN счёт (20)» → «Расчётный RUB счёт (20)»
- Генератор «Наименование организаций на английском языке»:
    - увеличена дистанция с 25 до 130;
    - формат названия приведён к более корректному виду: тип компании теперь формируется в конце названия (ранее был в начале)
- Генератор «Наименование организаций на русском языке»:
    - увеличена дистанция с 25 до 130;
    - добавлены новые типы организаций

### ⚙️ Технические изменения

- Подключён Dependabot для автоматического обновления зависимостей (Gradle и GitHub Actions) с ежедневной проверкой
- Добавлены тесты на проверку уникальности зарегистрированных действий в общем списке генераторов
- Полностью изменена структура проекта: выполнен переход на многомодульную архитектуру
- Реализованы бенчмарки для всех генераторов на базе [JMH](https://github.com/openjdk/jmh)
- Плагин собран под версию [IntelliJ IDEA 2026.1](https://www.jetbrains.com/idea/whatsnew/2026-1/)

- Тестирование: подключён [Kover](https://github.com/Kotlin/kotlinx-kover) для формирования отчёта о покрытии кода тестами.
- Документация: добавлена [Dokka](https://github.com/Kotlin/dokka) для генерации документации. В сгенерированной документации теперь
  присутствует ссылка на отчёт Kover.
- CI/CD: настроен GitHub Actions workflow для автоматической сборки и тестирования проекта.
- Репозиторий: на страницу GitHub добавлены основные бейджи (статус сборки, покрытие тестами, версия и т.д.).
- Реализована отдельная группа нагрузочных тестов для анализа качества генераторов. Эти тесты автоматически определяют, через сколько
  итераций генераторы начинают создавать повторяющиеся значения. Запуск тестов вынесен в отдельную конфигурацию для оптимизации времени
  выполнения основных тестов.
