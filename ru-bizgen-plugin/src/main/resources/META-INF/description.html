Russian test data generator for IntelliJ IDEA and all JetBrains IDEs. Generate INN, OGRN, KPP, SNILS, BIK, SWIFT, IBAN, bank accounts, card numbers, passports, full names, addresses and phone numbers — with valid checksums, right in the editor. Also available as an MCP server for AI agents.

Генератор российских тестовых данных прямо в редакторе. ИНН, ОГРН, КПП, СНИЛС, БИК, SWIFT, IBAN, расчётные счета, номера карт, паспорта, ФИО, адреса и телефоны — с корректными контрольными суммами, без копирования из сторонних сервисов.

Плагин зависит только от ядра платформы, поэтому работает во всех IDE на IntelliJ Platform: IntelliJ IDEA, PyCharm, GoLand, WebStorm, PhpStorm, RubyMine, CLion, Rider, DataGrip, DataSpell, RustRover, Android Studio.

⚠️ Важно:

Любые совпадения с реальными конфиденциальными данными (ИНН, номера счетов, наименования организаций, ОГРН, ОКТМО, СНИЛС, номера телефонов и другие) являются случайными и не предназначены для использования в реальных системах. Тестовые данные генерируются внутри плагина — без обращений к внешним сервисам.

  • 🔢 Прочее: UUID

🤖 MCP-сервер

Помимо плагина, доступен отдельный MCP-сервер (Model Context Protocol), который предоставляет аналогичный функционал генераторов и может быть развёрнут локально или в Docker. MCP-сервер позволяет использовать генераторы Ru BizGen в любых MCP-совместимых клиентах (IDE, AI-ассистенты, CI-инструменты).

Возможности MCP-сервера:

  • 🔧 5 категорийных инструментов — ru-bizgen_generator_<category> с параметром type (enum) и count для пакетной генерации
  • 🌐 Streamable HTTP транспорт на базе Ktor/Netty
  • 🐳 Docker-ready — multi-stage сборка, порт 8081
  • 🩺 Health endpoint /health для мониторинга
  • 🔒 Локальная генерация — без обращений к внешним сервисам
  • 🔁 Единый реестр генераторов с ядром ru-bizgen-core

Подробнее о настройке и запуске — в репозитории проекта: раздел ru-bizgen-mcp.

Как использовать:

Вызовите окно генератора с помощью горячей клавиши или через меню IDE — выберите нужный тип данных и вставьте результат прямо в код.

Способы вызова:

  • Ctrl+Alt+E (Windows/Linux) или ⌘⌥E (Mac)
  • Alt+Ins → Ru BizGen
  • Shift+Shift → Ru BizGen

Горячие клавиши можно изменить в настройках IDE.

Расширенные настройки:

Настройки → Tools → Ru BizGen
